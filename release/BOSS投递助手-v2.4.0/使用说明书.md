# BOSS投递助手 · 使用说明书

> 版本：v2.4.0  
> 作者：wok  
> 适用页面：BOSS直聘网页版职位列表页、聊天页  
> 适用浏览器：Chrome / Edge 桌面版（需要安装 Tampermonkey）

---

## 一、这个脚本能做什么

BOSS投递助手是一个浏览器用户脚本（userscript），主要做两件事：

1. **职位页自动投递**
   - 自动滚动收集当前职位列表
   - 逐个打开岗位，抓取岗位要求
   - 把「岗位要求 + 你的简历 + 你的投递要求」交给 AI 判断
   - AI 判定通过后，自动点击「立即沟通」

2. **聊天页辅助**
   - 「仅新消息」：只处理会话列表最上面一条
   - 「自动轮询」：从会话列表第一条到底部，逐条打开处理，到尾部自动停止
   - 按规则补发打招呼后续消息
   - 可自动发送附件简历 / 图片简历
   - 可按开关处理「交换联系方式」卡片

> AI 只用于岗位判定，不会自动生成聊天回复。

## 二、使用前准备

### 1. 浏览器

建议使用最新版 **Chrome** 或 **Edge** 桌面浏览器。

### 2. 安装 Tampermonkey

从 Tampermonkey 官网或浏览器扩展商店安装：

- 官网：https://www.tampermonkey.net/
- 安装后在浏览器工具栏能看到 Tampermonkey 图标

### 3. 准备一个 AI 接口

脚本需要一个兼容 OpenAI 协议的接口，例如：

- DeepSeek：https://platform.deepseek.com/
- 通义、OpenAI 或其它兼容 OpenAI 协议的中转站也可以

记下三项信息：

| 项目 | 示例 |
| --- | --- |
| API 地址 | `https://api.deepseek.com/v1/chat/completions` |
| API Key | `sk-xxxxxxxx` |
| 模型名称 | `deepseek-chat` |

> API Key 是 AI 服务商的密钥，不是 BOSS 账号密码。  
> AI 判定会消耗 token，请留意服务商余额和计费。

### 4. BOSS 账号设置

打开 BOSS 直聘网页版，进入设置页，确认已开启「打招呼语」功能。  
没有开启时，职位页可能找不到「立即沟通」按钮。

---

## 三、安装脚本

1. 点击浏览器工具栏的 Tampermonkey 图标
2. 选择「管理面板 / Dashboard」
3. 点击「+」或「添加新脚本」
4. 删除编辑器里的默认示例代码
5. 把 `boss-quick-apply.user.js` 的全部内容复制进去
6. 按 `Ctrl + S` 保存
7. 打开 BOSS 直聘职位列表页：

   https://www.zhipin.com/web/geek/jobs

8. 页面右侧出现蓝色面板，说明安装成功  
   如果没出现，刷新一次页面（`Ctrl + F5`）

---

## 四、首次配置

点击面板右上角的齿轮图标打开设置。设置是**一个长页面**，从上到下依次是：

1. AI API 配置
2. 投递提示词
3. 投递基础设置
4. 打招呼设置
5. 简历发送设置
6. 其他

### 1. AI API 配置

填写：

- API 地址
- API Key
- 模型名称

点击「测试连接」，确认能正常返回内容。  
然后点击「保存 API 配置」。

### 2. 投递提示词

点击「编辑提示词」，在弹窗里填写：

- 【我的简历】
- 【我的投递要求】

投递要求可以直接用自然语言写，例如：

```
只投杭州或上海的岗位；
期望薪资 15k 以上；
技术栈以后端 Go / Python 为主；
不接受纯外包、外派；
公司规模 50 人以上的自研团队优先。
```

可用变量只有：

- `{jobTitle}`：岗位标题
- `{jobDescription}`：岗位要求

其它 `{xxx}` 不会被替换，会原样发给 AI。  
编辑完成后点击弹窗里的「保存」。

### 3. 投递基础设置

建议配置：

| 设置 | 建议 |
| --- | --- |
| 投递招聘者状态 | 不筛选就保持「不限」 |
| 投递时排除猎头 | 按需开启 |
| 投递节奏 | 建议 2500ms 以上 |
| 单次投递上限 | 建议不超过 50 |

> 投递节奏过小、单次数量过大，容易触发平台风控。

### 4. 打招呼设置

「打招呼列表」是两段式：

- **第 1 行**：填你在 BOSS 设置页里配置的**网页自动打招呼语**
- **第 2 行及以后**：脚本要接着发送的后续消息

脚本会检查当前会话**最后一条我方消息**：

- 与第 1 行一致 → 发送第 2 行及以后的内容
- 不一致 / 第 1 行为空 → 什么都不发，也不记账

> 第 1 行必须和 BOSS 网页实际发出的招呼语完全一致，否则不会发送后续消息。

### 5. 简历发送设置

按需开启：

- 自动发送附件简历
- 发送图片简历（需先添加 JPG/JPEG 图片）

### 6. 其他

「自动同意交换」默认关闭。  
开启后，HR 发来交换联系方式卡片时脚本会自动点「同意」，等于把你的联系方式交给对方。请确认后再开启。

所有设置修改完成后，点击底部「保存设置」。

## 五、职位页：自动投递

1. 打开 BOSS 直聘职位列表页
2. 正常搜索、筛选出你想要的岗位
3. 点击面板上的「开始投递」
4. 脚本会：

   ```
   滚动收集岗位 → 打开详情 → 抓取岗位要求 → AI 判定 → 通过后点「立即沟通」
   ```

5. 运行中可随时点击「停止投递」

### 日志说明

每个岗位会在日志区显示结果，例如：

```
[3/20] 后端开发工程师 ✅ 通过：技术栈与经验匹配
[4/20] 销售代表     ❌ 跳过：销售岗不符合投递要求
```

底部统计：

- 已沟通
- 已跳过
- 失败

### 注意

- 点「立即沟通」的瞬间，BOSS 会用它自己配置的招呼语发出第一条消息，脚本拦不住
- 列表页本身不会发送自定义招呼语
- AI 判定失败（没配 Key、网络失败、返回格式异常）一律按「不投」处理
- 每个岗位会消耗一次 AI 调用

## 六、聊天页：处理 HR 会话

打开聊天页：

https://www.zhipin.com/web/geek/chat

面板上选择沟通模式：

### 仅新消息

只看会话列表最上面一条，有变化时才处理。  
适合只接新会话。

### 自动轮询

从会话列表第一条开始，逐条打开处理，到最后一条自动停止。

注意事项：

- **打开会话即标为已读**
- 每条会话在一轮里只打开一次
- 只有「最后一条我方消息 == 打招呼列表第 1 行」的会话才会收到后续消息
- 遍历开始后新出现的会话不会插队
- 到尾部会自动停止，按钮恢复「开始聊天」

### 发送简历

聊天页可自动发送：

- 附件简历
- 图片简历

只有对应开关打开、并且该 HR 还没有发送过对应简历时才会发送。

### 交换卡片

默认只记日志，不自动点「同意」。  
需要自动同意时，到设置 →「其他」里开启。

## 七、常见问题

### 1. 右侧面板没有出现

- 确认地址是 BOSS 职位列表页：`/web/geek/jobs`
- 刷新页面（`Ctrl + F5`）
- 确认 Tampermonkey 里脚本已启用
- 确认浏览器没有禁用 Tampermonkey

### 2. 点「开始投递」没反应

看日志区的提示，最常见原因是：

- 没有填写 API Key
- API 地址 / 模型名称不正确
- API 余额不足或网络不可用

### 3. 所有岗位都被跳过

查看日志里的 ❌ 原因：

- 「AI 判定失败」：检查 API Key、余额、地址、模型
- 「没抓到岗位要求」：换一个岗位或刷新页面再试
- 「招聘者状态不在筛选范围」：到设置里调整「投递招聘者状态」

### 4. 找不到「立即沟通」按钮

确认 BOSS 设置页已经开启「打招呼语」。

### 5. 聊天页没有发送后续消息

依次检查：

1. 打招呼列表第 1 行是否和 BOSS 网页实际发出的招呼语**完全一致**
2. 当前会话最后一条我方消息是否就是第 1 行
3. 打招呼列表第 2 行及以后是否填写了内容
4. 聊天页是否已经点击「开始聊天」

### 6. 设置没有保存

- 普通设置：点击底部「保存设置」
- AI API 配置：点击「保存 API 配置」
- 提示词：点击弹窗里的「保存」

### 7. 如何停止脚本

- 职位页：点「停止投递」
- 聊天页：点「停止聊天」
- 关闭页面或刷新页面也会停止当前任务

### 8. 如何卸载

打开 Tampermonkey 管理面板，找到「BOSS投递助手」，删除脚本即可。

## 八、安全与免责声明

- API Key 保存在浏览器本地（localStorage），请不要在公用电脑使用
- 岗位信息、简历内容、投递要求会发送给你配置的 AI 服务商
- 自动投递属于对 BOSS 直聘的自动化操作，可能触及平台风控
- 请自行控制投递频率和数量，建议投递间隔不低于 2500ms，单次不超过 50 个
- 使用本脚本产生的任何后果由使用者自行承担
- 请遵守 BOSS 直聘用户协议及当地法律法规
